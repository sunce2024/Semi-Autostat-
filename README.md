สำหรับโปรเจกต์ที่มีไฟล์ Python หลายไฟล์ (main_stat_edit1.py และโมดูลสถิติอีก 16 ไฟล์) พร้อมตัวรันคำสั่ง streamlit run 
เครื่องมือที่ช่วยให้แก้ไขและหาจุดผิดได้ง่ายที่สุดคือ Visual Studio Code (VS Code)

Library ที่ต้องติดตั้งเพิ่มผ่าน pip และ Library พื้นฐานที่มีมาพร้อมกับ Python อยู่แล้ว
:streamlit — สร้างหน้าเว็บ UI สำหรับกดปุ่มควบคุมขั้นตอนต่างๆ (st.tabs, st.button, st.columns ฯลฯ)
selenium — สั่งงานเปิด Chrome, เปลี่ยน URL, รอ Element โหลด (WebDriverWait) และกรอกข้อมูลลงฟอร์มเว็บpandas — อ่านและจัดการข้อมูลจากไฟล์ตารางสถิติ (pd.read_excel)
xlrd — Engine สำหรับอ่านไฟล์ Excel นามสกุลเก่า .xls (engine="xlrd")   
tkinter (มากับ Python ในเครื่อง) — ใช้แสดงหน้าต่าง Pop-up แจ้งเตือน (messagebox) เพื่อหยุดรอกดบันทึกข้อมูล
os และ time (มากับ Python ในเครื่อง) — จัดการ Path ของไฟล์ และหน่วงเวลาการรอโหลดหน้าเว็บ

ตัวอย่างติดตั้ง ไปที่ PowerShell
pip install streamlit selenium pandas xlrd

และรันไฟล์ check_env.py  เพื่อเช็คสภาพแวดล้อมก่อน

การรองรับเวอร์ชัน Pythonเวอร์ชัน: โค้ดชุดนี้รันอยู่บน Python 3.13 ได้ตามปกติ และ Streamlit เองก็รองรับ Python 3.11 และ 3.13 อยู่แล้ว  
แนวทางเลือกเวอร์ชัน Python: ควรใช้ Python 3.10 ขึ้นไป (แนะนำสาย 3.11 – 3.13) 
และหลีกเลี่ยงเวอร์ชันที่เก่ามากอย่าง Python 3.9 ลงไป เพราะ Library รุ่นใหม่ๆ ทยอยยกเลิกการรองรับ Python รุ่นเก่าไปแล้ว
ข้อควรระวังเมื่อลง Python รุ่นใหม่ล่าสุด (เช่น Python 3.14+ หรือรุ่นใหม่กว่า): เวลามี Python ออกเวอร์ชันใหม่ๆ บาง Library
โดยเฉพาะ pandas หรือ xlrd อาจยังไม่มีไฟล์ติดตั้งสำเร็จรูป (wheel) รองรับในทันที หรือมีจุดเปลี่ยนพฤติกรรมบางอย่าง
หากนำไปติดตั้งบนเครื่องอื่น แนะนำให้ใช้ Python 3.11 หรือ 3.12 หรือ 3.13 เหมือนเครื่องปัจจุบันจะเสถียรและลดโอกาสเจอปัญหา Package ไม่เข้ากันได้มากที่สุดครับ
